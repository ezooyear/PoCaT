# Eligibility Agent

고객 정보와 상품 조건을 비교해 각 상품의 가입 가능 여부를 구조화된 형태로 정리하는 에이전트입니다.

## 역할

- 고객 정보와 상품 조건을 비교하여 가입 가능 여부를 판단합니다.
- 추천을 직접 하지 않고, Recommend Agent가 사용할 판단 결과를 정리합니다.

## 입력 데이터

| 항목 | 설명 |
|---|---|
| `customer_agent` 결과 | 고객의 나이, 직업, 월 저축 가능 금액, 우대조건 관련 정보 |
| `product_agent` 결과 | 상품명, 가입 대상, 가입 조건, 판매 여부, 납입 한도 등 상품 정보 |

## 출력 데이터

| 항목 | 설명 |
|---|---|
| `eligibility_results` | 상품별 가입 가능 여부를 담은 구조화 결과 |

## 상태 구분

| 상태 | 의미 | 예시 |
|---|---|---|
| `eligible` | 가입 가능 | 조건 충족, 판매 중, 금액 범위 충족 |
| `check_required` | 추가 정보 확인 필요 | 군인 여부 확인 필요, 미소드림 대상 여부 확인 필요, 소득 기준 확인 필요 |
| `rejected` | 가입 불가 | 나이 조건 불충족, 판매 종료 상품, 가입 금액 조건 미충족 |

## 주요 판단 기준

- 나이
- 직업
- 가입 금액
- 판매 여부
- 우대조건 충족 여부

## 설계 원칙

- 정보가 부족하면 즉시 탈락시키지 않습니다.
- 추가 확인이 필요한 상품은 `check_required`로 분류합니다.
- Recommend Agent가 다시 가입 가능 여부를 판단하지 않도록 구조화된 결과를 제공합니다.
